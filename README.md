# Edge-SCADA

Легковесная веб-ориентированная система сбора данных и диспетчерского управления (SCADA) на чистом асинхронном Python (`asyncio`).

Проект связывает промышленный контроллер (ПЛК с датчиками) и веб-интерфейс оператора: опрашивает контроллер по протоколу Modbus TCP, обрабатывает измерения в оперативной памяти, отсекает шум, сохраняет историю в SQLite и транслирует данные в реальном времени в браузер.

---

## Как это устроено (на пальцах)

Вся система работает в одном асинхронном процессе и разделена на простые модули:

```text
[ ПЛК / Симулятор ] 
        │
        │  Modbus TCP (порт 5020)
        ▼
[ Polling Engine ] ──────> [ In-Memory Bus ]
(опрос раз в 1 сек)        (актуальные теги в RAM)
                                 │            │
             (архив в фоне)      │            │  (живой экран)
                                 ▼            ▼
                        [ Deadband Filter ] [ WebSockets ]
                                 │            │
                                 ▼            ▼
                         [ База SQLite ]  [ Браузер ]
```

1. **`src/simulator/` (Виртуальный ПЛК):** Имитирует физический контроллер. Меняет значения в регистрах памяти (как будто нагревается котел или растет давление) и слушает сетевой порт 5020.
2. **`src/da/` (Data Acquisition / Движок опроса):** Раз в секунду делает сетевой запрос к ПЛК по протоколу Modbus TCP (функция 03), забирает сырые байты и упаковывает их в понятные объекты — **Теги (`Tag`)**.
3. **`src/core/` (Ядро системы):**
   * `bus.py` (**Шина данных в памяти**): Простой и быстрый словарь в RAM, где всегда лежат самые свежие значения всех датчиков. Развязывает модули между собой: опросчик складывает данные, а сайт и база их оттуда забирают.
   * `deadband.py` (**Фильтр зоны нечувствительности**): Отсекает микроколебания датчиков (шум), чтобы не забивать базу терабайтами одинаковых цифр.
4. **`src/storage/` (Хранение):** Фоновое сохранение истории тегов в базу данных SQLite для графиков и отчетов.
5. **`src/api/` и `src/web/` (Веб-интерфейс):** Сервер FastAPI + WebSockets для живого отображения телеметрии и REST API для выдачи исторических графиков.

## Быстрый запуск

### 1. Подготовка окружения
Требуется Python 3.11+.

```bash
# Клонирование и переход в папку проекта
git clone https://github.com/lakuhome/mini-scada.git
cd mini-scada

# Создание и активация виртуального окружения
python -m venv venv

# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux/macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
pip install pytest
```

### 2. Запуск симулятора контроллера (Терминал 1)
Запускает виртуальный ПЛК, который слушает порт `5020` и меняет значения регистров:
```bash
python -m src.simulator.virtual_plc
```

### 3. Запуск движка опроса (Терминал 2)
Подключается к ПЛК по Modbus TCP и начинает считывать данные:
```bash
python -m src.da.polling_engine
```

### 4. Запуск тестов
```bash
pytest
```
