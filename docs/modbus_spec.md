# Спецификация Modbus TCP в проекте

Документ описывает структуру сетевых пакетов между движком опроса (`PollingEngine`) и контроллером (`VirtualPLC`).

Связь работает по обычному TCP-сокету (порт `5020`). Все числа из нескольких байт передаются в сетевом порядке байт — **Big-Endian** (в Python для модуля `struct` это символ `>`).

---

## 1. Структура сетевого пакета

Любой пакет Modbus TCP (и запрос, и ответ) состоит из двух частей:
1. **Заголовок MBAP (7 байт)** — указывает номер транзакции, длину и адрес устройства.
2. **Данные PDU (Protocol Data Unit)** — код команды (функции) и сами данные.

### Поля заголовка MBAP (7 байт):

| Поле | Размер | Формат `struct` | Значение | Назначение |
|---|---|---|---|---|
| **Transaction ID** | 2 байта | `>H` | 1, 2, 3... | Номер запроса. Сервер возвращает этот же номер в ответе, чтобы клиент сопоставил ответ с запросом. |
| **Protocol ID** | 2 байта | `>H` | Всегда `0` | Признак протокола Modbus. |
| **Length** | 2 байта | `>H` | Длина в байтах | Длина оставшейся части пакета (Unit ID + PDU). |
| **Unit ID** | 1 байт | `>B` | Обычно `1` | Адрес устройства на шине. |

## 2. Используемые команды (функции)

В проекте используются две базовые функции Modbus:

### Функция 03: Чтение регистров (Read Holding Registers)
Используется движком опроса для считывания текущих показаний с ПЛК.

#### Запрос от опросчика к ПЛК:
Опросчик запрашивает: «начиная с адреса 0, отдай мне 5 регистров».
* Код функции: `0x03` (1 байт).
* Начальный адрес: `0x0000` (2 байта).
* Количество регистров: `5` (2 байта).

Сборка запроса в Python:
```python
# Заголовок MBAP (7 байт) + PDU (5 байт) = 12 байт
request = struct.pack(
    '>HHHBBHH',
    tx_id,          # Transaction ID
    0,              # Protocol ID (0)
    6,              # Length (Unit ID + 5 байт PDU = 6)
    1,              # Unit ID (1)
    3,              # Function Code (3)
    start_address,  # Начальный адрес (0)
    register_count  # Количество регистров (5)
)
```

#### Ответ от ПЛК:
Контроллер возвращает сырые байты:
* Код функции: `0x03` (1 байт).
* Количество байт данных: `10` (1 байт, так как 5 регистров по 2 байта = 10 байт).
* Значения регистров: 10 байт данных (5 чисел `uint16`).

Разбор ответа в Python:
```python
# Считываем 7 байт заголовка:
mbap = await reader.readexactly(7)
tx_id, proto, length, unit_id = struct.unpack('>HHHB', mbap)

# Считываем length - 1 байт полезной нагрузки:
pdu = await reader.readexactly(length - 1)
func_code = pdu[0]
byte_count = pdu[1]

# Распаковываем 16-битные числа:
values = struct.unpack(f'>{byte_count // 2}H', pdu[2:])
# Получаем кортеж: (750, 210, 1, 0, 800)
```

### Функция 06: Запись одного регистра (Write Single Register)
Используется для отправки команды на контроллер (изменить уставку температуры или включить насос).

* Код функции: `0x06` (1 байт).
* Адрес регистра: 2 байта (`>H`).
* Новое значение: 2 байта (`>H`).

По стандарту Modbus при успешной записи контроллер возвращает точную копию отправленного запроса (эхо), подтверждая, что значение сохранено в памяти.
