# Низкоуровневая спецификация протокола Modbus TCP (Layer 1)

Этот документ описывает бинарный формат обмена данными между Polling Engine (клиентом) и ПЛК (сервером) в рамках реализации нашей Edge-SCADA. Связь построена на сырых TCP-сокетах с использованием Big-Endian (сетевого порядка байт).

## 1. Структура фрейма Modbus TCP

Каждый запрос и ответ состоит из двух частей:
1. **MBAP Header (7 байт)** — заголовка транспортного уровня.
2. **PDU (Protocol Data Unit)** — полезной нагрузки, зависящей от кода функции.

### MBAP Header (7 байт)
*   **Transaction ID (2 байта, `H`):** Идентификатор транзакции. Используется клиентом для сопоставления запроса и ответа.
*   **Protocol ID (2 байта, `H`):** Идентификатор протокола. Для Modbus всегда равен `0`.
*   **Length (2 байта, `H`):** Количество оставшихся байт в сообщении (считая от поля Unit ID до конца пакета).
*   **Unit ID (1 байт, `B`):** Идентификатор устройства (адрес ведомого), в нашем симуляторе обычно `1`.

## 2. Спецификация поддерживаемых функций

### Функция 03: Чтение Holding Registers (Read Holding Registers)
Используется Polling Engine для считывания блоков памяти (датчиков и переменных).

*   **Запрос (PDU от клиента):**
    *   Код функции: `1 байт` (`0x03`)
    *   Начальный адрес: `2 байта` (`H`, с какого регистра начинать чтение)
    *   Количество регистров: `2 байта` (`H`, сколько регистров подряд запросить)
*   **Ответ (PDU от сервера):**
    *   Код функции: `1 байт` (`0x03`)
    *   Количество байт данных (Byte Count): `1 байт` (`B`, равно `кол-во регистров * 2`)
    *   Значения регистров: `N * 2 байт` (каждый регистр занимает 2 байта, формат `>H`)

### Функция 06: Запись одного регистра (Write Single Register)
Используется для отправки управляющих команд (уставок) на контроллер.

*   **Запрос (PDU от клиента):**
    *   Код функции: `1 байт` (`0x06`)
    *   Адрес регистра: `2 байта` (`H`)
    *   Значение для записи: `2 байта` (`H`)
*   **Ответ (Эхо от сервера):**
    *   По стандарту Modbus при успешной записи сервер возвращает **абсолютно точную копию запроса** (эхо-пакет), подтверждая, что значение записано в память.
