# Спецификация визуального конструктора мнемосхем (JSON Schema)

Документ описывает структуру автономного конструктора схем оборудования и формат выходного файла конфигурации (`config.json`).

---

## 1. Назначение и концепция

Конструктор мнемосхем — это легковесный инструмент визуального проектирования технологических схем.

* **Автономность:** работает целиком на стороне браузера (HTML5/JS), не требует запущенного бэкенда или БД для сборки схем.
* **Результат работы:** генерирует файл конфигурации (`config.json`), связывающий графические элементы схемы с тегами Modbus шины данных (`InMemoryBus`).
* **Стандартизация:** использует общепринятые обозначения промышленной автоматизации (ГОСТ 21.404-93, ГОСТ 2.784-96, ГОСТ 2.782-96).

---

## 2. Базовые типы оборудования

Всё подключаемое оборудование разбито на 5 стандартных технологических примитивов:

| Тип (`type`) | Назначение | ГОСТ / Стандарт | Привязка к сигналам |
|---|---|---|---|
| **`sensor_temp`** | Датчик температуры | ГОСТ 21.404-93 (символ «T») | Входной аналоговый тег (`float`) |
| **`sensor_pressure`** | Датчик давления | ГОСТ 21.404-93 (символ «P») | Входной аналоговый тег (`float`) |
| **`pump`** | Насос / электромотор | ГОСТ 2.782-96 | Дискретный статус работы (`0` / `1`) |
| **`valve`** | Запорный клапан / задвижка | ГОСТ 2.784-96 (символ «⧓») | Дискретный статус (`0` = закрыт, `1` = открыт) |
| **`boiler`** | Котёл / нагреватель | ГОСТ 2.793-79 | Аналоговый тег температуры + уставка |

## 3. Спецификация формата данных (`config.json`)

Конструктор экспортирует схему в виде JSON-документа:

```json
{
  "version": "1.0",
  "title": "Схема котельной №1",
  "grid": {
    "width": 1200,
    "height": 800,
    "cell_size": 20
  },
  "widgets": [
    {
      "id": "boiler_01",
      "type": "boiler",
      "title": "Основной котёл",
      "x": 140,
      "y": 180,
      "tag_id": "Boiler_Temp_01",
      "tag_setpoint": "Temp_Setpoint_01",
      "unit": "°C",
      "min_val": 20.0,
      "max_val": 100.0
    },
    {
      "id": "pump_01",
      "type": "pump",
      "title": "Циркуляционный насос",
      "x": 360,
      "y": 200,
      "tag_id": "Pump_01_Status",
      "unit": ""
    },
    {
      "id": "press_01",
      "type": "sensor_pressure",
      "title": "Давление в контуре",
      "x": 520,
      "y": 180,
      "tag_id": "System_Pressure_01",
      "unit": "бар",
      "min_val": 0.0,
      "max_val": 6.0
    }
  ]
}
```

### Поля виджета:
* **`id`** (`str`): Уникальный строковый идентификатор виджета на схеме.
* **`type`** (`str`): Тип графического элемента из таблицы выше.
* **`title`** (`str`): Пользовательское название прибора на экране.
* **`x`, `y`** (`int`): Координаты левого верхнего угла блока в пикселях.
* **`tag_id`** (`str`): Идентификатор тега в шине данных `InMemoryBus` для отображения значения.
* **`tag_setpoint`** (`str`, опционально): Тег уставки Modbus FC 06 для записи команды.
* **`unit`** (`str`): Единица физической величины (`°C`, `бар`, `%`, `кВт`).
* **`min_val`, `max_val`** (`float`, опционально): Аварийные границы или шкала прибора.

## 4. Требования к интерфейсу конструктора (`constructor.html`)

1. **Левая панель (Палитра компонентов):**
   * Кнопки добавления 5 базовых типов оборудования.
   * Клик или перетаскивание на холст добавляет новый элемент.
2. **Центральная панель (Холст):**
   * Координатная сетка с шагом 20px.
   * Возможность свободного перемещения элементов мышью (Drag & Drop).
   * Выделение активного элемента по клику.
3. **Правая панель (Свойства выбранного элемента):**
   * Редактирование названия, `tag_id`, единиц измерения и диапазона.
   * Кнопка удаления элемента со схемы.
4. **Верхняя панель управления:**
   * Кнопка **«Экспорт JSON»** — открытие модального окна с готовым кодом и кнопкой копирования в буфер.
   * Кнопка **«Импорт JSON»** — вставка ранее сохраненного конфига и перерисовка схемы.
   * Кнопка **«Очистить всё»**.
