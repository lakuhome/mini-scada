# Спецификация визуального конструктора мнемосхем (JSON Schema)

Документ описывает структуру конструктора технологических мнемосхем, классификацию промышленного оборудования по ГОСТ / ISA-5.1 и формат выходного файла конфигурации (`config.json`).

---

## 1. Назначение и концепция

Конструктор мнемосхем — легковесный инструмент визуального проектирования технологических схем.

* **Автономность:** работает на чистом HTML5/JS (без сторонних фреймворков и без обязательного бэкенда при создании схемы).
* **Результат работы:** генерирует файл конфигурации (`config.json`), связывающий графические элементы схемы с тегами шины данных (`InMemoryBus`).
* **Стандартизация:** использует исчерпывающий набор условных графических обозначений (УГО) по ГОСТ и международному стандарту ISA-5.1 (P&ID).

---

## 2. Полный каталог промышленного оборудования (14 примитивов)

Всё многообразие технологического оборудования в промышленности делится на 6 базовых функциональных групп:

### Группа 1. Ёмкости и аппараты (ГОСТ 2.793-79)
| Тип (`type`) | Название | Графический вид | Привязка к сигналам |
|---|---|---|---|
| **`tank_vertical`** | Вертикальный бак / резервуар | Цилиндр с полукруглым верхом | Уровень (L), температура (T) |
| **`tank_horizontal`** | Горизонтальная цистерна | Горизонтальный цилиндр | Уровень (L), давление (P) |
| **`boiler`** | Котёл / реактор / печь | Аппарат с символом нагрева | Температура (T) + уставка нагрева |

### Группа 2. Гидравлика и вентиляция (ГОСТ 2.782-96, ГОСТ 2.780-96)
| Тип (`type`) | Название | Графический вид | Привязка к сигналам |
|---|---|---|---|
| **`pump`** | Насос | Окружность с направленным треугольником потока | Статус работы (`0`/`1`), авария |
| **`fan`** | Вентилятор / компрессор | Окружность с лопастями | Статус работы (`0`/`1`), скорость |
| **`motor`** | Электропривод / мотор | Окружность с литерой «M» | Статус питания (`0`/`1`), ток |

### Группа 3. Запорно-регулирующая арматура (ГОСТ 2.784-96, ГОСТ 2.785-70)
| Тип (`type`) | Название | Графический вид | Привязка к сигналам |
|---|---|---|---|
| **`valve`** | Запорный кран / клапан | Сомкнутые треугольники («песочные часы» ⧓) | Концевик открыт/закрыт (`0`/`1`) |
| **`control_valve`** | Регулирующий клапан | Клапан с грибком мембранного привода | Процент открытия ($0..100\%$) |
| **`gate_valve`** | Задвижка трубопроводная | Клапан с вертикальной заслонкой | Статус положения |

### Группа 4. Теплообменное оборудование (ГОСТ 2.793-79)
| Тип (`type`) | Название | Графический вид | Привязка к сигналам |
|---|---|---|---|
| **`heat_exchanger`** | Теплообменник | Аппарат со змеевиком | Температура входа/выхода |
| **`heater`** | Электрический ТЭН / нагреватель | Зигзагообразная спираль | Дискретный статус / мощность |

### Группа 5. Приборы КИПиА и датчики (ГОСТ 21.404-93)
В соответствии с ГОСТ 21.404-93 датчик графически представляет собой окружность с буквенным обозначением измеряемой величины:
| Тип (`type`) | Обозначение | Измеряемый параметр | Привязка к сигналам |
|---|---|---|---|
| **`sensor_temp`** | **( T )** | Температура | Входной аналоговый тег (`float`) |
| **`sensor_pressure`** | **( P )** | Давление | Входной аналоговый тег (`float`) |
| **`sensor_level`** | **( L )** | Уровень жидкости/сыпучих | Входной аналоговый тег (`float`) |
| **`sensor_flow`** | **( F )** | Расход среды | Входной аналоговый тег (`float`) |

### Группа 6. Механический транспорт
| Тип (`type`) | Название | Графический вид | Привязка к сигналам |
|---|---|---|---|
| **`conveyor`** | Ленточный конвейер / шнек | Конвейерная лента со стрелкой хода | Статус хода (`0`/`1`), скорость |


### Спецификация полей объекта виджета:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| **`id`** | `string` | Да | Уникальный идентификатор элемента на схеме |
| **`type`** | `string` | Да | Идентификатор типа из каталога 14 элементов |
| **`title`** | `string` | Да | Человекочитаемое название («Котёл №1») |
| **`x`**, **`y`** | `integer` | Да | Координаты левого верхнего угла (в px, кратны 20) |
| **`tag_id`** | `string \| null` | Нет | Тег шины данных для чтения телеметрии (FC 03) |
| **`tag_setpoint`** | `string \| null` | Нет | Тег шины данных для отправки уставки/команды (FC 06) |
| **`unit`** | `string` | Нет | Единица измерения (`°C`, `бар`, `%`, `м³/ч`, `об/мин`) |
| **`min_val`**, **`max_val`** | `float \| null` | Нет | Границы шкалы / технологические аварийные уставки |

## 4. Требования к интерфейсу автономного конструктора (`constructor.html`)

1. **Палитра элементов (левая колонка):**
   * Сгруппирована по категориям: *Ёмкости*, *Насосы/Вентиляторы*, *Арматура*, *Теплообмен*, *Датчики (T, P, L, F)*, *Транспорт*.
   * Каждый элемент отображается с канонической SVG-иконкой по ГОСТ.
2. **Рабочий холст (центральная зона):**
   * Фоновая координатная сетка (шаг 20 пикселей).
   * Поддержка перемещения (Drag & Drop) с привязкой к сетке.
   * Визуальное выделение активного компонента рамкой.
3. **Панель инспектора свойств (правая колонка):**
   * При выборе элемента отображает форму редактирования параметров (`title`, `tag_id`, `tag_setpoint`, `unit`, `min_val`, `max_val`).
   * Кнопка «Удалить элемент».
4. **Панель управления (верхняя строка):**
   * **«Экспорт JSON»** — открытие всплывающего окна с готовой JSON-структурой и кнопкой копирования в буфер обмена.
   * **«Импорт JSON»** — поле для вставки ранее сохраненного конфига и мгновенная перерисовка схемы на холсте.
   * **«Очистить холст»** — сброс текущей схемы.
