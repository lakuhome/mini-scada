# Границы MVP

Уточнено владельцем проекта 05.11.2026: конструктор мнемосхем исключён.
React + Vite остаются стеком фиксированной страницы оператора (ADR-002).

## Обязательный сценарий

1. Запуск из чистого клона командой `docker compose up --build`.
2. На странице отображаются температура, давление, насос, авария и уставка виртуального ПЛК.
3. Теги имеют время и качество. При обрыве или таймауте данные становятся BAD.
4. После восстановления ПЛК опрос возобновляется автоматически, теги становятся GOOD.
5. Страница получает WebSocket-снимки, различает потерю сервера и потерю ПЛК.
6. Разрешённая уставка проходит серверную проверку; результат подтверждается чтением.
7. История хранится в SQLite WAL и доступна в таблице с фильтром времени.
8. После перезапуска контейнеров история сохраняется.

## Проверка готовности

Python-тесты проверяют собственный Modbus, шину, фильтр, SQLite и сквозной сценарий
с настоящим TCP-соединением. Playwright проверяет интерфейс, команду, историю,
два браузерных клиента и переподключение. Сборка React и тесты входят в CI.
Отдельно проверяется Compose: запуск, остановка/возврат ПЛК и сохранение тома истории.
Успешные модульные тесты не заменяют эту проверку развёртывания.

## За пределами MVP

Конструктор и импорт мнемосхем, библиотека промышленных примитивов, сложные графики,
учётные записи и роли, удалённое развёртывание, физический ПЛК, несколько контроллеров,
сторонние брокеры и Time-Series DB. Планы прежней КТ-2, связанные с редактором,
заменены этим согласованным объёмом. Результат КТ-1 остаётся в теге `kt01-v1`.
