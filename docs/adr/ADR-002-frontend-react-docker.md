# ADR-002: React + Vite и сборка через Docker

Статус: принято. Исходная дата: 08.10.2026. Уточнение границ: 05.11.2026.

Интерфейс оператора реализуется на React + Vite. FastAPI раздаёт собранные
статические файлы, предоставляет REST API и WebSocket. Многоэтапный Dockerfile
собирает интерфейс в Node.js и копирует результат в Python-образ.

По решению владельца проекта от 05.11.2026 конструктор мнемосхем исключён из MVP.
Старый экспериментальный schema designer не используется. React остаётся принятым
стеком для мониторинга, изменения разрешённой уставки и просмотра истории.

Для MVP достаточно фиксированной панели котельной. Импорт схем, перетаскивание,
каталог графических примитивов и произвольное проектирование оборудования не входят
в критерии готовности. Конфигурация записи определяется сервером, а не браузером.
