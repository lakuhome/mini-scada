# Архитектура mini-scada

## Процессы и границы

Виртуальный ПЛК — отдельный процесс с Modbus TCP-сервером. Приложение FastAPI
работает в одном Python-процессе и одном asyncio event loop: опросчик, шина,
архиватор, REST и WebSocket. React работает в браузере. Не запускайте несколько
Uvicorn workers: каждый создал бы независимые шину и опросчик.

## Сбор и архивирование

`src/da/polling_engine.py` читает FC03, проверяет MBAP/PDU, публикует Tag в
`src/core/bus.py`. Подключение и чтение ограничены таймаутом. При ошибке соединение
закрывается, теги переходят в BAD, затем выполняется повторное подключение.

Шина хранит копии тегов и передаёт отдельные снимки в очереди подписчиков.
`src/storage/service.py` потребляет очередь и пропускает значения через DeadbandFilter.
Смена качества проходит независимо от числового порога. Database пишет историю
через `asyncio.to_thread`, с WAL, индексом по тегу и времени, сериализацией операций.

API при старте открывает SQLite, запускает архиватор, затем опросчик на общей шине.
При остановке отменяет опрос, дожидается очереди архива, останавливает архиватор
и закрывает базу. При длительной недоступности диска очередь архива может расти:
дисковая буферизация и гарантированная доставка после аварии процесса не входят в MVP.

## Экран и управление

`/ws/tags` отправляет полный снимок шины каждые 0.5 секунды. Для каждого клиента
есть собственные задачи отправки и обнаружения отключения; отправка ограничена
таймаутом, отдельной неограниченной очереди для браузера нет.

React скрывает недостоверные текущие значения, различает BAD и отключение
WebSocket, повторно подключается и закрывает зависший канал без пакетов за 5 секунд.
История получается REST-запросом, обновляется по выбору тега/периода или кнопке.

Шина и БД хранят сырые значения. `src/core/catalog.py` задаёт адрес, единицу и divisor.
Клиент делит raw на divisor; сервер умножает физическую уставку на divisor и проверяет
точность представления, uint16 и SafetyLimits. Ограничения загрузки JSON из браузера нет:
политику задаёт только `SCADA_SAFETY_LIMITS` на сервере, по умолчанию запись запрещена.

PLCCommandService последовательно отправляет FC06 с таймаутами и проверяет ответ.
Страница сначала сообщает о приёме команды, затем ждёт GOOD-тег с целевым значением
и временем новее серверного `acknowledged_at` в ответе команды. Часы браузера не
участвуют в проверке. Без подтверждения за 10 секунд сообщает об этом.

## Сборка и каталоги

`frontend/` содержит React + Vite. В Docker первый этап Node.js 24 собирает dist,
второй этап Python раздаёт его через FastAPI. Compose запускает ПЛК и приложение,
публикует HTTP на localhost и сохраняет SQLite в volume.

`src/simulator/` — ПЛК; `src/da/` — сбор; `src/core/` — Tag, шина, фильтр, лимиты;
`src/storage/` — история; `src/api/` — шлюз; `src/tests/` — Python-тесты;
`frontend/tests/` — браузерные тесты. Конструктор мнемосхем удалён из актуального объёма.
