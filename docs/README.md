# Документация проекта mini-scada

В этой папке собраны технические описания, спецификации протоколов, результаты обследования и архитектурные решения.

---

## Разделы документации

### 1. Документы первой контрольной точки (КТ-1)
* **[Протокол предпроектного обследования (`interview_protocol.md`)](interview_protocol.md)**
  * Результаты интервью с заказчиком / преподавателем.
  * Основной сценарий, критические ограничения, подтвержденные потребности vs рабочие гипотезы.
* **[Границы MVP и сквозной сценарий (`mvp_scope.md`)](mvp_scope.md)**
  * Базовый сквозной сценарий: `Симулятор -> Опрос -> Шина -> Фильтр -> Архив/Веб`.
  * Разделение на обязательное ядро (Must Have) и резервный бэклог.
  * Регламент переноса функций (ADR / CR).
* **[ADR-001: Выбор стека и инструментальный контур (`adr/ADR-001-tech-stack.md`)](adr/ADR-001-tech-stack.md)**
  * Обоснование выбора Python 3.11+, чистого `asyncio`, рукописного Modbus TCP и SQLite WAL.
  * Матрица 7 позиций инструментального контура КТП с маршрутом подключения в семестре.

### 2. Технические спецификации и архитектура
* **[Архитектура системы (`architecture.md`)](architecture.md)**
  * Главный принцип: один асинхронный процесс (`asyncio`).
  * Разделение потоков: быстрый (живые данные в браузер) и архивный (история в SQLite).
  * Роль шины данных в памяти (`InMemoryBus`) и фильтра дребезга (`DeadbandFilter`).
  * Зоны ответственности каждого каталога в `src/`.
* **[Спецификация Modbus TCP (`modbus_spec.md`)](modbus_spec.md)**
  * Сетевой заголовок MBAP (7 байт).
  * Функция 03 (чтение регистров) и функция 06 (запись уставки).
  * Примеры упаковки и распаковки бинарных пакетов в Python (`struct.pack` / `struct.unpack`).
* **[Контракт данных: Модель Тега (`tag_contract.md`)](tag_contract.md)**
  * Структура объекта `Tag` (`id`, `value`, `timestamp`, `quality`).
  * Обработка статусов качества (`GOOD`, `BAD`) при обрыве связи.
  * Пример создания и обновления тегов в коде.

### 3. Человеко-машинный интерфейс (HMI / SCADA)
* **[Спецификация конструктора мнемосхем (`schema_designer_spec.md`)](schema_designer_spec.md)**
  * Полный каталог 14 примитивов промышленного оборудования по ГОСТ и ISA-5.1.
  * Структура формата конфигурации (`config.json`).
  * Требования к интерфейсу автономного веб-конструктора мнемосхем.
